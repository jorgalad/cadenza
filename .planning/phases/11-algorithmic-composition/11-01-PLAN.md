    **2. Create `src/cadenza/composition/markov.py`:**
    - `MarkovModel` frozen dataclass: `@dataclass(frozen=True, slots=True)` with fields `order: int` and `transition_table: dict[tuple[int, ...], dict[int, float]]`. The transition table maps MIDI n-grams to probability distributions over successor MIDI numbers. Do NOT define `__hash__` -- MarkovModel is not intended as a dict key.
    - `train_markov(phrase: Phrase, order: int = 1) -> MarkovModel`:
      - Validate order >= 1, raise ValueError otherwise.
      - Filter phrase to Notes only (skip Rests).
      - Validate len(notes) > order, raise ValueError if insufficient data.
      - Extract MIDI numbers from notes.
      - Build transition table: for each position i, key = tuple(midis[i:i+order]), value = midis[i+order]. Accumulate counts, then normalize to probabilities (count/total).
      - Return `MarkovModel(order=order, transition_table=prob_table)`.
    - `markov_melody(model: MarkovModel, length: int, seed: int | None = None, duration: Duration | None = None) -> Phrase`:
      - Validate length > 0, raise ValueError otherwise.
      - Create `rng = random.Random(seed)`.
      - Default duration: `Duration.from_cn("q")` if duration is None.
      - Pick random initial state from table keys via `rng.choice(states)`.
      - Seed result_midis with the initial state's MIDI values.
      - Loop until len(result_midis) >= length: lookup state in table, use `rng.choices(pitches, weights=weights)` to pick successor. On dead-end (state not in table), restart from random state.
      - Truncate to `length`, convert via `from_midi(m)` to Notes.
      - Return `tuple(events)`.

    **3. Create `src/cadenza/composition/lsystem.py`:**
    - `lsystem_melody(axiom: str, rules: dict[str, str], alphabet: dict[str, Note | Rest], generations: int) -> Phrase`:
      - Validate generations >= 0, raise ValueError otherwise.
      - String rewriting loop: `current = axiom`, then for each generation, replace each character using `rules.get(ch, ch)`.
      - Translate: `events = [alphabet[ch] for ch in current if ch in alphabet]`.
      - Return `tuple(events)`.

    **1. Create `src/cadenza/composition/stochastic.py`:**

    All three functions use `import random as _random` and create `rng = _random.Random(seed)` per call.
    All three accept an optional `duration: Duration | None = None` parameter, defaulting to `Duration.from_cn("q")`.

    - `probabilistic_melody(weights: dict[Pitch, float], length: int, seed: int | None = None, duration: Duration | None = None) -> Phrase`:
      - Validate length > 0, raise ValueError.
      - Validate weights non-empty, raise ValueError.
      - Use `rng.choices(list(weights.keys()), weights=list(weights.values()), k=1)[0]` for each note.
      - Return tuple of Notes with chosen pitches and default duration.

    - `tendency_mask_melody(mask: Callable[[float], dict[Pitch, float]], length: int, seed: int | None = None, duration: Duration | None = None) -> Phrase`:
      - Validate length > 0, raise ValueError.
      - For each position i in range(length), compute `t = i / max(length - 1, 1)` (normalized to [0.0, 1.0]).
      - Call `mask(t)` to get pitch weights at this position.
      - Use `rng.choices` with those weights to pick a pitch.
      - Return tuple of Notes.

    - `random_walk(start: Pitch, length: int, scale: Scale, max_step: int = 2, seed: int | None = None, duration: Duration | None = None) -> Phrase`:
      - Validate length > 0, max_step >= 1, raise ValueError otherwise.
      - Use `nearest_in_scale(start, scale)` to snap start to scale.
      - For each subsequent note: generate candidates from -max_step to +max_step semitones (excluding 0), snap each via `from_midi` then `nearest_in_scale`, collect unique candidates, pick one via `rng.choice`.
      - If no candidates (shouldn't happen with reasonable scales), stay on current pitch.
      - Return tuple of Notes.
