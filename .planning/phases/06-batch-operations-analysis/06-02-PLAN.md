    **ANAL-01 ambitus:**
    `ambitus(phrase: Phrase) -> tuple[Pitch, Pitch]`: extract notes, raise ValueError if empty. Find min and max by `midi_number` property. Return `(lowest, highest)`.

    **ANAL-02 melodic_contour:**
    `melodic_contour(phrase: Phrase) -> list[str]`: extract notes. For each consecutive pair, compare midi_number. Return "U" if curr > prev, "D" if curr < prev, "S" if equal.

    **ANAL-03 interval_sequence:**
    `interval_sequence(phrase: Phrase) -> list[Interval]`: extract notes. For each consecutive pair, call `Interval.between(notes[i].pitch, notes[i+1].pitch)`.

    **ANAL-04 pitch_class_histogram:**
    `pitch_class_histogram(phrase: Phrase) -> dict[int, int]`: extract notes. Use `collections.Counter(note.pitch.pitch_class for note in notes)`. Return as plain dict.

    **ANAL-05 rhythmic_density:**
    `rhythmic_density(phrase: Phrase, window: Fraction = Fraction(1, 4)) -> list[float]`: compute onset time for each event by accumulating durations (onset of first event = 0). For each time window `[w*window, (w+1)*window)`, count Notes whose onset falls in that range. Total duration = sum of all event durations. Number of windows = `ceil(total_duration / window)`. Return `list[float]` of counts.

    **ANAL-06 complexity_score:**
    `complexity_score(phrase: Phrase) -> float`: extract notes. If < 2 notes, return 0.0. Compute:
    1. `interval_variety = len(set(abs(iv.semitones) for iv in interval_sequence(phrase))) / max(len(intervals), 1)` where intervals = interval_sequence(phrase)
    2. `rhythm_variety = len(set(n.duration.fraction for n in notes)) / len(notes)`
    3. `contour = melodic_contour(phrase)`, `direction_changes = sum(1 for i in range(1, len(contour)) if contour[i] != contour[i-1])`, `contour_change_rate = direction_changes / max(len(contour) - 1, 1)` if len(contour) > 1 else 0.0
    4. Return `(interval_variety + rhythm_variety + contour_change_rate) / 3.0`

    **ANAL-07 find_motifs:**
    Define `MotifMatch` frozen dataclass:
    ```python
    @dataclass(frozen=True, slots=True)
    class MotifMatch:
        motif: Phrase
        positions: tuple[int, ...]
    ```
    `find_motifs(phrase: Phrase, min_length: int = 2) -> list[MotifMatch]`:
    - Extract notes only (with their original indices in phrase stored).
    - Use a fingerprint for comparison: for each note, `(note.pitch.midi_number, note.duration.fraction)`.
    - For each possible motif length from `min_length` to `len(notes) // 2`:
      - Slide a window across the note fingerprint list.
      - Group identical fingerprint subsequences by their content (use tuple as dict key).
      - Keep only those appearing 2+ times.
    - Build MotifMatch objects with the actual sub-phrase (from the first occurrence) and 0-based event indices (indices in the original phrase, not just note indices).
    - Return sorted by motif length descending, then by first position ascending.

    **ANAL-08 phrase_similarity:**
    `phrase_similarity(phrase1: Phrase, phrase2: Phrase) -> float`:
    - `_pitch_similarity`: extract MIDI sequences from both. Use ratio of matching elements (like Jaccard on aligned sequences). For unequal lengths, pad shorter with None and count matches. Specifically: `matches = sum(1 for a, b in zip(midi1, midi2) if a == b)`, `score = matches / max(len(midi1), len(midi2), 1)`.
    - `_rhythm_similarity`: extract duration fraction sequences. Same aligned matching.
    - `_contour_similarity`: compute contours, same aligned matching.
    - Return `(pitch_score + rhythm_score + contour_score) / 3.0`.

    **ANAL-09 detect_sequence:**
    Define `SequenceMatch` frozen dataclass:
    ```python
    @dataclass(frozen=True, slots=True)
    class SequenceMatch:
        match_type: str  # "exact" or "transposed"
        offset: int  # 0-based event index in phrase1 where match starts
        transposition: Interval | None  # None for exact, Interval for transposed
    ```
    `detect_sequence(phrase1: Phrase, phrase2: Phrase) -> list[SequenceMatch]`:
    - Extract notes from both phrases.
    - For exact match: slide phrase2 notes (by MIDI+duration fingerprint) across phrase1 notes. If a match is found, record SequenceMatch("exact", event_index_in_phrase1, None).
    - For transposed match: compute interval sequences of both. Slide phrase2's interval sequence across phrase1's interval sequence. If match found, compute the transposition interval between first notes. Record SequenceMatch("transposed", event_index, transposition_interval).
    - Return all matches found. Return empty list if none.
