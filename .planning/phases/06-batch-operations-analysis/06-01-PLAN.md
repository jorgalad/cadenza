    **mutations.py** (BATCH-01, BATCH-02, BATCH-03, BATCH-04):
    - Define `DYNAMICS: tuple[str, ...] = ("ppp", "pp", "p", "mp", "mf", "f", "ff", "fff")` and `DYNAMIC_INDEX: dict[str, int]` mapping.
    - Implement `_map_nth_notes(phrase, n, fn)` private helper: iterates events, counts only `isinstance(event, Note)`, applies `fn` to every Nth Note (1-indexed, so note_count % n == 0 means Nth), passes Rests and non-Nth Notes unchanged. Returns `tuple(result)`.
    - `set_articulation_nth(phrase: Phrase, n: int, articulation: str) -> Phrase`: validates n >= 1, uses `_map_nth_notes` with `lambda note: replace(note, articulations=note.articulations + (articulation,) if articulation not in note.articulations else note.articulations)`.
    - `set_dynamic_nth(phrase: Phrase, n: int, dynamic: str) -> Phrase`: validates n >= 1, uses `_map_nth_notes` with `lambda note: replace(note, dynamic=dynamic)`.
    - `crescendo(phrase: Phrase, start: str, end: str) -> Phrase`: validates `DYNAMIC_INDEX[start] < DYNAMIC_INDEX[end]` (ValueError otherwise). Collects `(index, note)` pairs for Notes only. For each Note at position `pos` (0-based in note list), computes `dyn_idx = round(start_idx + (end_idx - start_idx) * pos / max(n_notes - 1, 1))`. Uses `replace(note, dynamic=DYNAMICS[dyn_idx])`. Single-note phrase gets end dynamic.
    - `decrescendo(phrase: Phrase, start: str, end: str) -> Phrase`: validates `DYNAMIC_INDEX[start] > DYNAMIC_INDEX[end]` (ValueError otherwise). Same proportional logic as crescendo.
    - `add_articulation_if(phrase: Phrase, predicate: Callable[[Event], bool], articulation: str) -> Phrase`: iterates all events. For Notes matching predicate, adds articulation (skip if already present). Rests matching predicate are passed unchanged (articulations only on Notes).
    - `remove_articulation_if(phrase: Phrase, predicate: Callable[[Event], bool], articulation: str) -> Phrase`: for matching Notes, creates new articulations tuple excluding the target.

    **pitch_ops.py** (BATCH-07, BATCH-08):
    - `replace_pitch(phrase: Phrase, old: Pitch, new: Pitch, *, by_class: bool = False) -> Phrase`: iterates events. For Notes: if `by_class=False`, exact `note.pitch == old` comparison; if `by_class=True`, compare `note.pitch.pitch_class == old.pitch_class` and construct new pitch preserving octave offset (`new_octave = note.pitch.octave + (new.octave - old.octave)` -- actually simpler: `Pitch(new.step, new.accidental, note.pitch.octave)`). Uses `replace(note, pitch=...)`.
    - `filter_phrase(phrase: Phrase, predicate: Callable[[Event], bool]) -> Phrase`: `return tuple(e for e in phrase if predicate(e))`.

    **rhythm_ops.py** (BATCH-05):
    - `quantize_lengths(phrase: Phrase, grid: Fraction) -> Phrase`: delegate to `cadenza.transforms.rhythm.quantize(phrase, grid)`. This is a re-export/thin wrapper for API consistency in the batch package. If `rhythm.quantize` only snaps durations, this is identical. Import and call directly.

    **humanize.py** (BATCH-06):
    - `humanize(phrase: Phrase, seed: int | None = None) -> Phrase`: create `rng = random.Random(seed)`. Iterate events. For `isinstance(event, Note) and event.dynamic is not None`: lookup `idx = DYNAMIC_INDEX[event.dynamic]`, `shift = rng.choice([-1, 0, 1])`, `new_idx = max(0, min(len(DYNAMICS) - 1, idx + shift))`, `replace(event, dynamic=DYNAMICS[new_idx])`. Else pass through. Import DYNAMICS and DYNAMIC_INDEX from mutations.py.

    **windowed.py** (BATCH-09):
    - `apply_windowed(phrase: Phrase, fn: Callable[[Phrase], Phrase], window_size: int, step: int | None = None) -> Phrase`: if step is None, step = window_size. Validate window_size >= 1 and step >= 1 (ValueError). Loop `i = 0; while i < len(phrase): window = phrase[i:i+window_size]; result.extend(fn(window)); i += step`. Return `tuple(result)`.
