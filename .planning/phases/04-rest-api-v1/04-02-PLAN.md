**1. Create src/cadenza/api/routes/transforms.py:**

Create an `APIRouter(prefix="/v1/transform", tags=["transforms"])`.

Each endpoint follows the pattern:
```python
@router.post("/chromatic-transpose", response_model=None, summary="Transpose phrase by chromatic interval")
def chromatic_transpose_endpoint(req: TransposeRequest) -> dict:
    phrase, _warnings = parse_cn(req.phrase)
    interval = parse_interval_string(req.interval)
    result = chromatic_transpose(phrase, interval)
    return {"phrase": to_cn(result), "events": _to_serializable(result)}
```

Implement these endpoints (all POST, all under `/v1/transform/`):

**Pitch transforms:**
- `/chromatic-transpose` — `TransposeRequest` -> `chromatic_transpose(phrase, parse_interval_string(req.interval))`
- `/diatonic-transpose` — `DiatonicTransposeRequest` -> `diatonic_transpose(phrase, req.n, get_scale(parse_pitch_string(req.phrase[...]), req.scale_name) if scale_name else None)`. IMPORTANT: diatonic_transpose takes `n` (int steps) and optionally a `Scale` object. Parse scale_name: if provided, need a root pitch. Use the first pitch of the parsed phrase as the scale root. Construct scale via `get_scale(first_pitch, req.scale_name)` where `first_pitch` = first Note's pitch from the parsed phrase.
- `/invert` — `InvertRequest` -> `invert(phrase, parse_pitch_string(req.axis) if req.axis else None)`
- `/pitch-retrograde` — `PhraseOnlyRequest` -> `pitch_retrograde(phrase)`
- `/full-retrograde` — `PhraseOnlyRequest` -> `full_retrograde(phrase)`
- `/retrograde-inversion` — `InvertRequest` -> `retrograde_inversion(phrase, parse_pitch_string(req.axis) if req.axis else None)`. Reuse InvertRequest schema (it has phrase + optional axis).

**Rhythm transforms:**
- `/augment` — `RatioRequest` -> `augment(phrase, Fraction(req.ratio).limit_denominator(1000))`
- `/diminish` — `RatioRequest` -> `diminish(phrase, Fraction(req.ratio).limit_denominator(1000))`
- `/rhythmic-retrograde` — `PhraseOnlyRequest` -> `rhythmic_retrograde(phrase)`
- `/rhythmic-rotation` — `RotateRequest` -> `rhythmic_rotation(phrase, req.n)`
- `/extract-rhythm` — `PhraseOnlyRequest` -> returns `{"events": _to_serializable(extract_rhythm(phrase))}` (no CN phrase output -- returns durations, not a phrase). Use `response_model=None`.
- `/total-duration` — `PhraseOnlyRequest` -> returns `{"total": str(total_duration(phrase)), "numerator": int, "denominator": int}`. Custom response (not a phrase).
- `/quantize` — `QuantizeRequest` -> `quantize(phrase, req.grid)` (grid values are string duration tokens like "q", "e" which quantize already accepts).
- `/metric-modulation` — `MetricModulationRequest` -> Parse old_unit/new_unit as CN duration strings. Use a helper: parse a tiny CN snippet like `"old_unit c4"` to extract the Duration, or parse them directly. The simplest approach: `parse_cn(f"{req.old_unit} c4")` returns a phrase with one note whose Duration is the parsed value. Extract that Duration. Same for new_unit. Then call `metric_modulation(phrase, old_dur, new_dur)`.

**Melodic transforms:**
- `/rotate` — `RotateRequest` -> `rotate(phrase, req.n)`
- `/permute` — `PermuteRequest` -> `permute(phrase, req.indices)`
- `/interpolate` — `InterpolateRequest` -> `interpolate(phrase, req.steps)`
- `/omit` — `OmitRequest` -> `omit(phrase, n=req.n)` (predicate not HTTP-exposable)
- `/repeat` — `RepeatRequest` -> `repeat(phrase, req.n)` (variation not HTTP-exposable)
- `/mirror` — `PhraseOnlyRequest` -> `mirror(phrase)`
- `/fragment` — `FragmentRequest` -> `fragment(phrase, req.lengths)` returns `tuple[Phrase, ...]`. Use MultiPhraseResponse: `{"phrases": [{"phrase": to_cn(f), "events": _to_serializable(f)} for f in fragments]}`
- `/concatenate` — `ConcatenateRequest` -> parse each string in `req.phrases` with `parse_cn`, then `concatenate(*parsed_phrases)`. Single phrase response.
- `/interleave` — `InterleaveRequest` -> parse both `req.phrase` and `req.phrase2`, call `interleave(p1, p2)`. Single phrase response.

**Stub endpoints (NOT_IMPLEMENTED):**
- `/pitch-map` — raises `CadenzaAPIError(NOT_IMPLEMENTED, "pitch-map requires a Python callable; not available over HTTP", "")`
- `/swing` — raises `CadenzaAPIError(NOT_IMPLEMENTED, "swing is not yet implemented in the core library", "")`

**Response pattern for single-phrase results:**
```python
return {"phrase": to_cn(result), "events": _to_serializable(result)}
```

**Response pattern for multi-phrase results (fragment, diatonic-chords):**
```python
return {"phrases": [{"phrase": to_cn(p), "events": _to_serializable(p)} for p in results]}
```

**Error wrapping for specific error codes:**
Wrap calls that can fail with specific errors:
- `parse_pitch_string` failures: catch ValueError, raise `CadenzaAPIError(INVALID_PITCH, str(e), input_value)`
- `parse_interval_string` failures: catch ValueError, raise `CadenzaAPIError(INVALID_INTERVAL, str(e), input_value)`
- `get_scale` with unknown name: catch ValueError, raise `CadenzaAPIError(INVALID_SCALE_NAME, str(e), scale_name)`
- `get_chord` with unknown symbol: catch ValueError, raise `CadenzaAPIError(INVALID_CHORD_SYMBOL, str(e), symbol)`
- `parse_cn` failures: ParseError is already caught by the global handler -> INVALID_CN

Create helper functions at top of transforms.py to reduce repetition:
```python
def _parse_phrase(cn_string: str) -> Phrase:
    """Parse CN string, return phrase (discard warnings)."""
    phrase, _warnings = parse_cn(cn_string)
    return phrase

def _phrase_response(phrase: Phrase) -> dict:
    """Build standard {phrase, events} response dict."""
    return {"phrase": to_cn(phrase), "events": _to_serializable(phrase)}
```

**2. Create src/cadenza/api/routes/theory.py:**

Create an `APIRouter(prefix="/v1/theory", tags=["theory"])`.

Theory endpoints return pitch tuples, not Phrases. For the CN representation of pitch tuples, serialize as space-separated pitch strings: `" ".join(f"{p.step}{p.accidental if p.accidental != 'n' else ''}{p.octave}" for p in pitches)`. Create a helper `_pitches_to_cn(pitches: tuple[Pitch, ...]) -> str`.

For the events JSON of pitch tuples, use `[_to_serializable(p) for p in pitches]` (list of Pitch dicts).

Endpoints:
- `POST /scale` — `ScaleRequest` -> `get_scale(parse_pitch_string(req.root), req.name)`. Return `{"phrase": _pitches_to_cn(scale.pitches), "events": [_to_serializable(p) for p in scale.pitches]}`. Catch ValueError for unknown scale -> raise `CadenzaAPIError(INVALID_SCALE_NAME, str(e), req.name)`.

- `POST /diatonic-chords` — `DiatonicChordsRequest` -> `diatonic_chords(parse_pitch_string(req.root), req.scale_name, req.quality)`. Returns `tuple[tuple[Pitch, ...], ...]`. Use MultiPhraseResponse pattern: `{"phrases": [{"phrase": _pitches_to_cn(chord), "events": [_to_serializable(p) for p in chord]} for chord in chords]}`.
- `POST /secondary-dominant` — `SecondaryDominantRequest` -> `secondary_dominant(req.degree, parse_pitch_string(req.root), req.key_name)`. Single pitch tuple response.
