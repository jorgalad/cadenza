  <action>
    Create `src/cadenza/analysis/voiceleading.py` with:

    1. **VoiceLeadingViolation frozen dataclass** (slots=True):
       - Fields: `rule: str`, `voice1: str`, `voice2: str`, `position: int`, `interval: Interval`, `severity: str`
       - `rule` values: `'parallel_fifth'`, `'parallel_octave'`, `'voice_crossing'`, `'voice_overlap'`, `'large_leap'`, `'augmented_leap'`
       - `severity` values: `'error'`, `'warning'`, `'suggestion'`

    2. **`_extract_pitches(phrase: Phrase) -> list[Pitch | None]`** -- returns pitch for Notes, None for Rests.

    3. **`_check_parallels(pitches_a, pitches_b, voice_a, voice_b, target_semitones_mod12, rule_name) -> list[VoiceLeadingViolation]`**:
       - For each consecutive position pair (i-1, i), skip if any of the 4 pitches is None.
       - Compute `prev_interval = abs(Interval.between(prev_b, prev_a).semitones) % 12` and `curr_interval = abs(Interval.between(curr_b, curr_a).semitones) % 12`.
       - Check BOTH intervals match `target_semitones_mod12` (7 for fifths, 0 for octaves/unisons).
       - Check BOTH voices actually moved (not oblique): `prev_a.midi_number != curr_a.midi_number AND prev_b.midi_number != curr_b.midi_number`.
       - Check same direction: `(curr_a.midi_number - prev_a.midi_number)` and `(curr_b.midi_number - prev_b.midi_number)` have the same sign (both positive or both negative).
       - If all conditions met, append violation with severity='error', position=i, interval=Interval.between(curr_b, curr_a).

    4. **`_check_crossing(pitches_upper, pitches_lower, voice_upper, voice_lower) -> list[VoiceLeadingViolation]`**:
       - For each position i, if both pitches are non-None and `lower_pitch.midi_number > upper_pitch.midi_number`, append violation with rule='voice_crossing', severity='error'.
       - The "upper" voice is the one that appears FIRST in Score tuple order (per CONTEXT.md).

    5. **`_check_overlap(pitches_upper, pitches_lower, voice_upper, voice_lower) -> list[VoiceLeadingViolation]`**:
       - For each position i >= 1, check:
         - If upper voice at pos i goes below lower voice at pos i-1: `upper[i].midi_number < lower[i-1].midi_number` -> overlap violation on upper voice.
         - If lower voice at pos i goes above upper voice at pos i-1: `lower[i].midi_number > upper[i-1].midi_number` -> overlap violation on lower voice.
       - Skip positions where any referenced pitch is None.
       - severity='warning'.

    6. **`_check_leaps(pitches, voice_name) -> list[VoiceLeadingViolation]`**:
       - For each consecutive pair (i-1, i) within a single voice, skip if either is None.
       - Compute interval = Interval.between(pitches[i-1], pitches[i]).
       - If `abs(interval.semitones) > 12`: append violation with rule='large_leap', severity='warning', voice1=voice_name, voice2=voice_name.
       - If interval quality is 'A' or 'd' (augmented or diminished) AND `abs(interval.semitones) > 0`: append violation with rule='augmented_leap', severity='suggestion', voice1=voice_name, voice2=voice_name.

    7. **`check_voice_leading(score: Score) -> list[VoiceLeadingViolation]`**:
       - Extract all voice pitches via `_extract_pitches`.
       - Use `itertools.combinations(score._voices, 2)` to get all voice pairs. The FIRST voice in each pair is "upper" (earlier in Score order).
       - For each pair: run `_check_parallels` for fifths (target=7) and octaves (target=0), `_check_crossing`, `_check_overlap`.
       - For each individual voice: run `_check_leaps`.
       - Collect all violations, sort by `position`, return.
