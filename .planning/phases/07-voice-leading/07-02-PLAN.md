    Add `generate_inner_voices` to `src/cadenza/analysis/voiceleading.py`:

    ```python
    def generate_inner_voices(
        soprano: Phrase, bass: Phrase, n: int = 2,
        ranges: list[tuple[Pitch, Pitch]] | None = None,
    ) -> list[Phrase]:
    ```

    Implementation:
    1. Import `from cadenza.transforms.pitch import from_midi`.
    2. Define default ranges:
       ```python
       _DEFAULT_RANGES = [
           (Pitch("c", "n", 3), Pitch("g", "n", 5)),   # Alto
           (Pitch("c", "n", 2), Pitch("g", "n", 4)),   # Tenor
       ]
       ```
       If `ranges is None`, use `_DEFAULT_RANGES[:n]`. If `n > len(_DEFAULT_RANGES)` and no custom ranges, interpolate additional ranges between tenor low and alto high.
    3. If `ranges is not None` and `len(ranges) != n`, raise `ValueError`.
    4. Extract soprano pitches and bass pitches via `_extract_pitches`.
    5. Determine beat count as `min(len(soprano), len(bass))`.
    6. For each inner voice v (0..n-1):
       - Initialize `prev_midi` to the midpoint of the voice's range: `(low.midi_number + high.midi_number) // 2`.
       - For each beat position i (0..beat_count-1):
         - Get soprano and bass pitches at position i. If either is a rest, use `from_midi(prev_midi)` for the inner voice (or make it a Rest -- use from_midi for simplicity since CONTEXT.md says "best-effort").
         - Target midi = `prev_midi` (minimize movement).
         - Clamp to range: `clamped = max(low.midi_number, min(high.midi_number, prev_midi))`.
         - Create `Note(pitch=from_midi(clamped), duration=soprano[i].duration if i < len(soprano) else bass[i].duration, dynamic=None, articulations=())`.
         - Update `prev_midi = clamped`.
       - Collect notes into a tuple -> Phrase for this voice.
    7. Return list of Phrases ordered from highest range to lowest (alto first, then tenor).
