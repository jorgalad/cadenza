    2. Implement `import_midi(path: str | Path, grid: str = '16', prefer_sharps: bool = False) -> tuple[Phrase | Score, list[ImportWarning]]`:
       - Call `_require_mido()` to get mido module
       - Parse grid string to grid fraction: `Duration.from_cn(grid).fraction` gives the grid size as fraction of whole note. For grid='16', fraction = Fraction(1,16).
       - Open MIDI file: `mido = _require_mido(); mid = mido.MidiFile(str(path))`
       - Get `ticks_per_beat = mid.ticks_per_beat`
       - For each track: extract track name from `track_name` meta message (fallback: `'track_N'`)
       - For each track, pair note_on/note_off events:
         - Maintain `active_notes: dict[int, tuple[int, int]]` mapping midi_number -> (start_tick, velocity)
         - Accumulate absolute tick from delta times
         - On `note_on` with velocity > 0: store in active_notes
         - On `note_off` OR `note_on` with velocity == 0: pop from active_notes, compute duration_ticks = current_tick - start_tick
         - If duration_ticks == 0: add ImportWarning(element="zero-duration-note", position=f"tick {start_tick}", message="..."), skip
       - Convert each paired note:
         - `dur_frac = Fraction(duration_ticks, ticks_per_beat * 4)` (fraction of whole note)
         - Quantize: `quantized = _snap_to_grid(dur_frac, grid_fraction)` -- round to nearest multiple of grid_fraction. Formula: `round(dur_frac / grid_fraction) * grid_fraction`. Minimum = grid_fraction (no zero-duration).
         - `pitch = from_midi(midi_number, prefer_sharps=prefer_sharps)`
         - `dynamic = velocity_to_dynamic(velocity)`
         - `duration = fraction_to_best_duration(quantized)`
         - Store as `(start_tick, Note(pitch, duration, dynamic))`
       - Sort notes by start_tick
       - Insert Rest events for gaps: if next note start_tick > current note end_tick, insert Rest with quantized gap duration
       - Quantize gap durations the same way as note durations
       - Build Phrase tuple from sorted events
       - Filter tracks: skip tracks with no note events (e.g., tempo-only track 0 in Type 1 files)
       - Single track with notes -> return Phrase; multiple tracks with notes -> return Score.from_dict({name: phrase})

    3. Implement `_snap_to_grid(frac: Fraction, grid: Fraction) -> Fraction`:
       - `n = round(frac / grid)`; if `n < 1: n = 1`; return `n * grid`
