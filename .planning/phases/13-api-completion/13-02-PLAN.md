**1. Create `src/cadenza/api/routes/analysis.py`:**

Use `APIRouter(prefix="/v1/analysis", tags=["analysis"])`. Follow the thin-handler pattern from transforms.py.

Endpoints (all POST, all `response_model=None`):

Chord/key endpoints:
- `/identify-chord`: parse pitches string (space-separated, e.g. "c4 e4 g4") via `_safe_parse_pitch` for each, call `identify_chord(tuple(pitches))`, return `{"root": _pitch_to_cn(r.root), "symbol": r.symbol, "inversion": r.inversion, "pitches": _pitches_to_cn(r.pitches)}`
- `/detect-key`: `_parse_phrase(req.phrase)` -> `detect_key(phrase)` -> `{"root": _pitch_to_cn(r.root), "mode": r.mode, "confidence": r.confidence}`
- `/roman-numeral`: parse pitches for chord, parse key_root, call `identify_chord`, build `KeyResult(root=key_root, mode=req.key_mode, confidence=1.0)`, call `roman_numeral(chord, key)`, return `{"numeral": rn.numeral, "function": rn.function}`
- `/harmonic-rhythm`: `_parse_phrase` the phrase, parse key_root, build KeyResult, call `harmonic_rhythm(phrase, key)`, return list of `{"onset": str(hb.onset), "duration": str(hb.duration), "chord_root": _pitch_to_cn(hb.chord.root), "chord_symbol": hb.chord.symbol, "numeral": hb.numeral.numeral, "function": hb.numeral.function}`
- `/detect-modulations`: `_parse_phrase` -> `detect_modulations(phrase, req.window)` -> list of `{"position": m.position, "from_key": {"root": _pitch_to_cn(m.from_key.root), "mode": m.from_key.mode}, "to_key": {"root": _pitch_to_cn(m.to_key.root), "mode": m.to_key.mode}}`
- `/realize-chord`: parse root, call `from cadenza.theory import get_chord`, return `_pitch_tuple_response(pitches)` -- reuse theory's chord endpoint pattern

Voice leading endpoints:
- `/check-voice-leading`: parse each voice string in req.voices via `_parse_phrase`, build `Score("voice_0", p0, "voice_1", p1, ...)` from the parsed phrases, call `check_voice_leading(score)`, return `{"violations": [{"rule": v.rule, "voice1": v.voice1, "voice2": v.voice2, "position": v.position, "severity": v.severity} for v in violations]}`
- `/smooth-voice-leading`: parse space-separated pitch strings for chord1 and chord2, call `smooth_voice_leading(tuple(c1_pitches), tuple(c2_pitches))`, return `_pitch_tuple_response(result)`
- `/generate-inner-voices`: `_parse_phrase` soprano and bass, call `generate_inner_voices(soprano, bass, req.n)`, return `{"voices": [_phrase_response(v) for v in voices]}`

Phrase analysis endpoints:
- `/ambitus`: `_parse_phrase` -> `ambitus(phrase)` -> `{"low": _pitch_to_cn(low), "high": _pitch_to_cn(high)}`
- `/melodic-contour`: `_parse_phrase` -> `melodic_contour(phrase)` -> `{"contour": result}`
- `/interval-sequence`: `_parse_phrase` -> `interval_sequence(phrase)` -> `{"intervals": [{"quality": iv.quality, "number": iv.number} for iv in ivs]}`
- `/pitch-class-histogram`: `_parse_phrase` -> `pitch_class_histogram(phrase)` -> `{"histogram": result}`
- `/rhythmic-density`: `_parse_phrase` -> `rhythmic_density(phrase)` -> `{"density": result}`
- `/complexity-score`: `_parse_phrase` -> `complexity_score(phrase)` -> `{"score": result}`
- `/find-motifs`: `_parse_phrase` -> `find_motifs(phrase, req.min_length)` -> `{"motifs": [{"phrase": to_cn(m.motif), "positions": list(m.positions)} for m in motifs]}`
- `/phrase-similarity`: `_parse_phrase` both phrases -> `phrase_similarity(p1, p2)` -> `{"similarity": result}`
- `/detect-sequence`: `_parse_phrase` both phrases -> `detect_sequence(p1, p2)` -> `{"matches": [{"match_type": m.match_type, "offset": m.offset, "transposition": {"quality": m.transposition.quality, "number": m.transposition.number} if m.transposition else None} for m in matches]}`

Every endpoint must have `summary="..."` and `description="..."` kwargs.
