**Async endpoints** -- one per generation function:

```python
def _run_job(job_id: str, func, cf, above, **kwargs):
    """Execute counterpoint generation in background thread."""
    _jobs[job_id]["status"] = "running"
    try:
        result = func(cf, above=above, **kwargs)
        if isinstance(result, Score):
            _jobs[job_id]["result"] = _score_response(result)
        else:
            _jobs[job_id]["result"] = _counterpoint_score_response(cf, result, above)
        _jobs[job_id]["status"] = "done"
    except Exception as e:
        _jobs[job_id]["error"] = {"error": type(e).__name__, "message": str(e)}
        _jobs[job_id]["status"] = "failed"
    _jobs[job_id]["finished_at"] = time.monotonic()

def _submit_async(func, req_phrase: str, above: bool = True, **kwargs) -> dict:
    job_id = str(uuid.uuid4())
    _jobs[job_id] = {"status": "pending", "result": None, "error": None, "finished_at": None}
    cf = _parse_phrase(req_phrase)
    t = threading.Thread(target=_run_job, args=(job_id, func, cf, above), kwargs=kwargs, daemon=True)
    t.start()
    return {"job_id": job_id, "status": "pending"}
```

**2. Create `src/cadenza/api/routes/jobs.py`:**

Import the shared job store: `from cadenza.api.routes.counterpoint import _jobs, _JOB_TTL`

Single endpoint:
- `GET /{job_id}`: Look up `_jobs.get(job_id)`. If not found, return 404 with `{"error": "JOB_NOT_FOUND", "message": "..."}`. If found and `finished_at` is not None and `time.monotonic() - finished_at > _JOB_TTL`, delete from `_jobs`, return 410 with `{"error": "JOB_EXPIRED", "message": "..."}`. Otherwise return `{"job_id": job_id, "status": job["status"], "result": job["result"], "error": job["error"]}`.

Use `from fastapi.responses import JSONResponse` for custom status codes (410, 404).

- `/probabilistic-melody`: accept `ProbabilisticRequest(weights: dict[str, float], length, seed)`. The weights keys are pitch strings like "c4", "e4". Get scale via `from cadenza.theory import get_scale; scale = get_scale(root, req.scale_name)`. Call `random_walk(start_pitch, req.length, scale, req.max_step, req.seed)`.
