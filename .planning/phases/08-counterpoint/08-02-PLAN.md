    **generate_second_species(cf, above=True, range=None) -> Phrase:**
    - 2 CP notes per CF note. Each CF note's duration is halved for CP notes.
    - Duration: if CF note is whole, CP notes are half notes (Duration.from_cn("h")). If CF is half, CP is quarter, etc. Compute as Duration(fraction=cf_event.duration.fraction / 2, base=_half_base(cf_event.duration.base)).
    - Helper `_half_base(base)`: maps "w"->"h", "h"->"q", "q"->"e", "e"->"s", "s"->"t", "t"->"x".
    - Candidates for downbeat (even positions): consonant intervals only (same as first species).
    - Candidates for offbeat (odd positions): consonant OR stepwise from previous note (passing tone between two consonances). Validate that if offbeat is dissonant, it is approached and left by step (max 2 semitones movement in same direction).
    - No parallel fifths/octaves between consecutive downbeats.
    - First note may be a rest (half rest) followed by consonance on offbeat -- implement as: first downbeat can be consonant or a half rest.
    - Penultimate CF beat: CP must cadence properly.
    - Use _backtrack with expanded position count (2 * len(cf_pitches)).

    **generate_third_species(cf, above=True, range=None) -> Phrase:**
    - 4 CP notes per CF note. Duration = CF duration / 4.
    - Helper `_quarter_base(base)`: maps "w"->"q", "h"->"e", "q"->"s", "e"->"t".
    - First of four (positions 0,4,8...): consonant.
    - Others: passing tones, neighbor tones, cambiata (skip to dissonance, resolve by step in opposite direction) allowed.
    - No parallel fifths/octaves on consecutive strong beats (every 4th position).
    - Use _backtrack with position count 4 * len(cf_pitches).

    **generate_fourth_species(cf, above=True, range=None) -> Phrase:**
    - Syncopated: each CP note is held across the barline.
    - Same number of notes as CF but offset rhythmically (conceptually tied).
    - Model as: each CP pitch is chosen at the offbeat, held to the next downbeat.
    - On the downbeat, the held note may be dissonant (suspension).
    - Suspension MUST resolve stepwise downward on the next offbeat.
    - Standard suspensions above CF: 7-6 (held 7th resolves to 6th), 4-3, 9-8.
    - Standard suspensions below CF: 2-3, 5-6.
    - If the held note is consonant, no resolution needed (consonant syncopation).
    - Use a modified backtracking approach: at each position, choose pitch considering the CF note at current AND next position.
    - Output Phrase has same length as CF, each note with CF's duration.

    **generate_fifth_species(cf, above=True, range=None) -> Phrase:**
    - Florid: mix of whole, half, quarter note values.
    - At each CF beat, choose a rhythmic pattern: 1 whole (species I), 2 halves (species II), 4 quarters (species III), or syncopated (species IV).
    - Preference: use longer notes at start and end, shorter in middle. Use suspensions at strong beats.
    - Must demonstrate variety: at least 2 different rhythmic patterns used.
    - Apply the appropriate species rules for each beat's chosen pattern.
    - Output Phrase length varies based on rhythm choices.

    **generate_free_counterpoint(cf, above=True, range=None) -> Phrase:**
    - Tonal voice-leading conventions, no strict species rhythmic ratios.
    - Same number of notes as CF (1:1 ratio for simplicity, but with varied durations allowed from CF).
    - Consonant intervals preferred on beats, passing tones allowed.
    - No parallel fifths/octaves.
    - Prefer stepwise motion, resolve leaps.
    - More relaxed than strict species: no strict climax rule, no strict repeated-note prohibition.
    - Uses _backtrack with relaxed validate_fn.

    Update **src/cadenza/counterpoint/validation.py**: Extend `check_counterpoint` to handle species 2-5 and 0 (free):
    - Species 2: validate downbeat consonance (every 2nd CP note aligns with CF), offbeat passing tone legality.
    - Species 3: validate first-of-four consonance, passing/neighbor patterns.
    - Species 4: validate suspension preparation-dissonance-resolution chain. Flag `unresolved_suspension` if dissonant held note does not resolve stepwise down.
    - Species 5: validate per-beat according to the rhythmic pattern used at that beat.
    - Species 0 (free): check parallel 5ths/8ths and beat consonance only (relaxed).

    Update **src/cadenza/counterpoint/__init__.py**: Add all 5 new generation functions to re-exports.
