    **src/cadenza/counterpoint/_engine.py**: Shared backtracking search engine.
    ```python
    import random
    from cadenza.core.pitch import Pitch

    def _backtrack(
        cf_pitches: list[Pitch],
        candidates_fn: Callable[[int, list[Pitch], Pitch], list[Pitch]],
        validate_fn: Callable[[int, list[Pitch], Pitch, Pitch], bool],
        position: int,
        partial: list[Pitch],
    ) -> list[Pitch] | None:
    ```
    - Recursive depth-first search
    - At each position, get candidates from `candidates_fn(position, partial, cf_pitches[position])`
    - Shuffle candidates with `random.shuffle` for variety
    - For each candidate, call `validate_fn(position, partial, candidate, cf_pitches[position])`
    - If valid, append to partial, recurse. On success return partial. On failure, pop and try next.
    - Return None if no candidates work (dead end)

    **src/cadenza/counterpoint/generation.py**:
    ```python
    def generate_first_species(
        cf: Phrase,
        above: bool = True,
        range: tuple[Pitch, Pitch] | None = None,
    ) -> Phrase:
    ```
    Implementation:
    - Raise ValueError if cf is empty
    - Extract CF pitches from Note events (skip Rests)
    - Compute pitch range: if `range` provided use it; else default to 10th above/below CF range (±16 semitones from CF min/max)
    - Define `_first_species_candidates(position, partial, cf_pitch)`:
      - Generate all MIDI numbers in range
      - Filter to consonant intervals (semitones mod 12 in PERFECT_CONSONANCES | IMPERFECT_CONSONANCES)
      - If above=True, only MIDI >= cf_pitch.midi_number; if False, only MIDI <= cf_pitch.midi_number
      - If position == 0 or position == len(cf)-1: only perfect consonances (mod 12 in {0, 7})
      - Order candidates: stepwise from previous note first (if partial not empty), imperfect consonances before perfect
    - Define `_first_species_validate(position, partial, candidate, cf_pitch)`:
      - If position > 0: check no parallel fifth/octave with previous position
      - If position > 0: check no voice crossing
      - If position > 0: prefer contrary motion (not a hard constraint, but used in candidate ordering)
      - If position == len(cf)-2: candidate must be a step away from the final note's expected pitch (leading tone check)
      - No repeated notes (candidate != partial[-1] if partial)
      - No more than 3 consecutive parallel 3rds or 6ths
    - Call `_backtrack(cf_pitches, candidates_fn, validate_fn, 0, [])`
    - Convert resulting pitch list to Phrase: each pitch gets same duration as corresponding CF note, dynamic=None, articulations=()
    - Use `from_midi` to convert MIDI numbers to Pitch objects (prefer_sharps=True for above, False for below -- matches ascending sharp / descending flat convention)
