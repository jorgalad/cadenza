    **Step 2: Implement `src/cadenza/settheory/serial.py` (GREEN).**

    Create `ToneRow` as a frozen dataclass with `slots=True`:
    ```python
    @dataclass(frozen=True, slots=True)
    class ToneRow:
        pcs: tuple[int, ...]  # 12 pitch classes, all distinct

        def __post_init__(self) -> None:
            if len(self.pcs) != 12 or set(self.pcs) != set(range(12)):
                raise ValueError("ToneRow must contain all 12 pitch classes exactly once")
    ```

    Methods on ToneRow:
    - `prime(self, n: int) -> tuple[int, ...]`: Transpose original row so first note maps to `n`. Formula: `((pc - self.pcs[0] + n) % 12 for pc in self.pcs)`. This ensures P(0) has first note = 0.
    - `inversion(self, n: int) -> tuple[int, ...]`: `((n - (pc - self.pcs[0])) % 12 for pc in self.pcs)`. This inverts around the first note then transposes to n.
    - `retrograde(self, n: int) -> tuple[int, ...]`: `self.prime(n)[::-1]`.
    - `retrograde_inversion(self, n: int) -> tuple[int, ...]`: `self.inversion(n)[::-1]`.
    - `matrix(self) -> list[list[int]]`: Generate 12x12 matrix. P(0) is the first row. I(0) is the first column. Each row i starts on the pitch class from I(0)[i] and is a transposition of P(0).

    Matrix algorithm:
    ```python
    p0 = self.prime(0)
    i0 = self.inversion(0)
    return [[(pc - p0[0] + row_start) % 12 for pc in p0] for row_start in i0]
    ```
    Since p0[0] is 0, this simplifies to `[[(pc + row_start) % 12 for pc in p0] for row_start in i0]`.

    Standalone functions:
    - `is_all_interval(row: ToneRow | tuple[int, ...]) -> bool`: Check if all 11 adjacent intervals are distinct. Extract pcs tuple from ToneRow if needed. `intervals = [(row[i+1] - row[i]) % 12 for i in range(11)]`, return `len(set(intervals)) == 11`.
    - `is_combinatorial(row: ToneRow | tuple[int, ...]) -> dict[str, list[int]]`: Check P/I/R/RI hexachordal combinatoriality. For each transposition level 0-11, check if first hexachord of that form is disjoint from the first hexachord of P(0). Return dict mapping form type to list of combinatorial transposition levels.
    - `realize_row(row_form: tuple[int, ...], base_octave: int = 4, nearest: bool = False) -> tuple[Pitch, ...]`: Convert PC sequence to Pitch objects. If `nearest=False`, place all in `base_octave` (MIDI = `pc + (base_octave + 1) * 12`). If `nearest=True`, first note at base_octave, subsequent notes choose the octave placement closest to previous note's MIDI number. Use `from_midi` from `cadenza.transforms.pitch`.
    - `segment_row(row_form: tuple[int, ...], sizes: tuple[int, ...]) -> tuple[tuple[int, ...], ...]`: Validate `sum(sizes) == len(row_form)`, then slice. Raise ValueError if sizes don't match.
    - `derive_row(seed: frozenset[int]) -> ToneRow`: Validate `12 % len(seed) == 0`. Partition the 12 PCs into groups by trying transpositions of the seed first, then inversions. Each group must be disjoint from already-used PCs. Concatenate all segments into a ToneRow. Raise ValueError if partition fails. Import `prime_form` from `cadenza.settheory.pcset`.
