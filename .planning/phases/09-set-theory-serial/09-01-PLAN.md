    - `invert_pcs(pcs: frozenset[int]) -> frozenset[int]` -- `frozenset((12 - pc) % 12 for pc in pcs)`.
    - `transpose_pcs(pcs: frozenset[int], n: int) -> frozenset[int]` -- `frozenset((pc + n) % 12 for pc in pcs)`.
    - `is_subset(a: frozenset[int], b: frozenset[int]) -> bool` -- `a <= b` (but NOT `a == b`; proper subset check: `a < b`). Actually per standard set theory, subset includes equality, so use `a <= b`.
    - `is_superset(a: frozenset[int], b: frozenset[int]) -> bool` -- `a >= b`.
    - `is_z_related(a: frozenset[int], b: frozenset[int]) -> bool` -- same interval_vector but different prime_form.
    - `rp_relation(a: frozenset[int], b: frozenset[int]) -> bool` -- same cardinality, share at least one (n-1)-element subset with same prime form.
    - `r0(a: frozenset[int], b: frozenset[int]) -> bool` -- same interval vector.
    - `r1(a: frozenset[int], b: frozenset[int]) -> bool` -- IVs differ in exactly one position by exactly 1.
    - `r2(a: frozenset[int], b: frozenset[int]) -> bool` -- IVs differ in exactly two positions each by 1, changes are complementary (sum of diffs = 0).
