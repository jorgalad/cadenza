    **Internal helpers:**
    - `_scale_duration(dur: Duration, ratio: Fraction) -> Duration`: Return `Duration(fraction=dur.fraction * ratio, base=dur.base, dots=dur.dots, tuplet=dur.tuplet)` -- keep original OMN metadata as hint, fraction is source of truth.
    - `_map_durations(phrase: Phrase, fn: Callable[[Duration], Duration]) -> Phrase`: Iterate events; for both Note and Rest use `dataclasses.replace(event, duration=fn(event.duration))`. Return tuple.
    - `_to_fraction_ratio(ratio: Fraction | int | float) -> Fraction`: Convert float via `Fraction(ratio).limit_denominator(1000)`, int via `Fraction(ratio)`, pass Fraction through.

    **Public functions:**
    - `rhythmic_retrograde(phrase: Phrase) -> Phrase`:
      Guard empty. Extract durations list. Reverse durations list. Rebuild each event with `replace(event, duration=reversed_durations[i])`. Return tuple.
      Both Notes and Rests get swapped durations.

    - `augment(phrase: Phrase, ratio: Fraction | int | float) -> Phrase`:
      Guard empty. Convert ratio via `_to_fraction_ratio`. Return `_map_durations(phrase, lambda d: _scale_duration(d, r))`.

    - `diminish(phrase: Phrase, ratio: Fraction | int | float) -> Phrase`:
      Guard empty. Convert ratio. Return `_map_durations(phrase, lambda d: _scale_duration(d, Fraction(1) / r))`.

    - `rhythmic_rotation(phrase: Phrase, n: int) -> Phrase`:
      Guard empty. Extract durations `[event.duration for event in phrase]`. Rotate durations: `n = n % len(durations); rotated = durations[n:] + durations[:n]` (positive = left, per CONTEXT.md). Rebuild events with `replace(event, duration=rotated[i])`. Return tuple.

    - `metric_modulation(phrase: Phrase, old_unit: Duration, new_unit: Duration) -> Phrase`:
      Compute ratio = `new_unit.fraction / old_unit.fraction`. Return `augment(phrase, ratio)`.

    - `extract_rhythm(phrase: Phrase) -> tuple[Duration, ...]`:

For each event, find the grid Duration whose fraction is closest to `event.duration.fraction` (by `abs(diff)`), replace event's duration with that grid Duration. Return tuple.

    - `total_duration(phrase: Phrase) -> Fraction`:
      Return `sum((event.duration.fraction for event in phrase), Fraction(0))`.
