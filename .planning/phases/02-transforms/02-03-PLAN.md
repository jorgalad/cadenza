    **Public functions:**

    - `pitch_retrograde(phrase: Phrase) -> Phrase` (MELO-01):
      Guard empty. Find indices of Notes (not Rests). Extract pitches at those indices. Reverse pitch list. Rebuild: for each Note index, `replace(event, pitch=reversed_pitches[i])`. Rests stay in place.

    - `retrograde_inversion(phrase: Phrase, axis: Pitch | None = None) -> Phrase` (MELO-02):
      Return `_invert(pitch_retrograde(phrase), axis=axis)`.

    - `full_retrograde(phrase: Phrase) -> Phrase`:
      Return `phrase[::-1]`.

    - `rotate(phrase: Phrase, n: int) -> Phrase` (MELO-03):
      Guard empty. `n = n % len(phrase)`. Return `phrase[n:] + phrase[:n]`. Positive = left (per CONTEXT.md).

    - `permute(phrase: Phrase, indices: Sequence[int]) -> Phrase` (MELO-04):
      Validate len(indices) == len(phrase). Return `tuple(phrase[i] for i in indices)`.

    - `interpolate(phrase: Phrase, steps: int = 1) -> Phrase` (MELO-05):
      Guard empty or len < 2. For each consecutive pair of Notes, insert `steps` chromatic passing notes. Passing notes get pitches computed by dividing the semitone distance evenly. Duration of original note is subdivided: if original duration fraction is F, each note (original + passing notes) gets F / (steps + 1). If either event in pair is a Rest, no interpolation -- just keep original. Build result list iteratively: for each event except last, append the interpolated sub-sequence; append last event unchanged. Use `from_midi` for intermediate pitches (choose sharps/flats based on direction: ascending = sharps, descending = flats).

    - `omit(phrase: Phrase, n: int | None = None, predicate: Callable[[Event], bool] | None = None) -> Phrase` (MELO-06):
      If `n` provided: remove every nth event (1-indexed: n=2 removes events at indices 1,3,5...). Return `tuple(e for i, e in enumerate(phrase) if (i + 1) % n != 0)`.
      If `predicate` provided: remove events where `predicate(event)` is True. Return `tuple(e for e in phrase if not predicate(e))`.
      Exactly one of n or predicate must be provided; raise ValueError if both or neither.

    - `repeat(phrase: Phrase, n: int, variation: Callable[[int, Phrase], Phrase] | None = None) -> Phrase` (MELO-07):
      Result starts empty. For i in range(n): if variation, append variation(i, phrase); else append phrase. Return `tuple(event for rep in repetitions for event in rep)`.

    - `mirror(phrase: Phrase) -> Phrase` (MELO-08):
      Return `phrase + full_retrograde(phrase)`. This is "palindrome: phrase + retrograde of phrase" per CONTEXT.md.

    - `fragment(phrase: Phrase, lengths: Sequence[int]) -> tuple[Phrase, ...]` (MELO-09):
      Split phrase into sub-phrases of given lengths. `offset = 0; fragments = []; for L in lengths: fragments.append(phrase[offset:offset+L]); offset += L`. If sum(lengths) < len(phrase), remaining events are lost (caller's intent). Return `tuple(fragments)`.

    - `concatenate(*phrases: Phrase) -> Phrase` (MELO-10):
      Return `tuple(event for phrase in phrases for event in phrase)`.

    - `interleave(phrase1: Phrase, phrase2: Phrase) -> Phrase` (MELO-11):
      Use itertools-style interleaving. Result list. For i in range(max(len(phrase1), len(phrase2))): if i < len(phrase1) append phrase1[i]; if i < len(phrase2) append phrase2[i]. Return tuple.

    - `pitch_map(phrase: Phrase, fn: Callable[[Pitch], Pitch]) -> Phrase` (MELO-12):
      Return `_map_pitches(phrase, fn)`.
