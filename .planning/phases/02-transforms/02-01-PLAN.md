    Create `src/cadenza/transforms/pitch.py` implementing all functions:

    **Internal helpers:**
    - `_INDEX_TO_STEP = {v: k for k, v in STEP_INDEX.items()}` -- reverse lookup from index to letter name
    - `_SEMITONES_TO_ACC = {v: k for k, v in ACCIDENTAL_SEMITONES.items()}` -- reverse lookup for accidentals
    - `_MIDI_TO_PITCH_SHARP`: list of 12 (step, accidental) tuples for sharps preference: [("c","n"),("c","s"),("d","n"),("d","s"),("e","n"),("f","n"),("f","s"),("g","n"),("g","s"),("a","n"),("a","s"),("b","n")]
    - `_MIDI_TO_PITCH_FLAT`: list of 12 (step, accidental) tuples for flats preference: [("c","n"),("d","b"),("d","n"),("e","b"),("e","n"),("f","n"),("g","b"),("g","n"),("a","b"),("a","n"),("b","b"),("b","n")]

    - `_transpose_pitch(pitch: Pitch, interval: Interval) -> Pitch`:
      1. Compute target letter index: `(STEP_INDEX[pitch.step] + interval.direction * (interval.number - 1)) % 7`
      2. Look up target step from `_INDEX_TO_STEP`
      3. Compute target MIDI: `pitch.midi_number + interval.semitones`
      4. Derive octave: `(target_midi - STEP_SEMITONES[target_step]) / 12 - 1`, round to int
      5. Derive accidental: `target_midi - ((octave + 1) * 12 + STEP_SEMITONES[target_step])`, look up in `_SEMITONES_TO_ACC`
      6. Raise ValueError if accidental out of range (> double sharp/flat)
      7. Return `Pitch(step=target_step, accidental=accidental, octave=octave)`

    - `_map_pitches(phrase: Phrase, fn: Callable[[Pitch], Pitch]) -> Phrase`:
      Iterate events; for Note use `dataclasses.replace(event, pitch=fn(event.pitch))`, for Rest pass through. Return `tuple(events)`.

    **Public functions:**
    - `chromatic_transpose(phrase: Phrase, interval: Interval) -> Phrase`: Guard empty, then `_map_pitches(phrase, lambda p: _transpose_pitch(p, interval))`
    - `diatonic_transpose(phrase: Phrase, n: int, scale: Any = None) -> Phrase`: `raise NotImplementedError("Diatonic transpose requires Phase 3 scale library")`
    - `invert(phrase: Phrase, axis: Pitch | None = None) -> Phrase`: Guard empty. Default axis = first Note's pitch. For each note, compute `Interval.between(axis, note.pitch)`, create reflected interval with `direction=-iv.direction`, transpose axis by reflected interval. Use `_map_pitches`.
    - `interval_between(p1: Pitch, p2: Pitch) -> Interval`: Thin wrapper around `Interval.between(p1, p2)`
    - `enharmonic_respell(pitch: Pitch, prefer_sharps: bool = True) -> Pitch`: Use `from_midi(pitch.midi_number, prefer_sharps=prefer_sharps)` to get the canonical spelling
    - `pitch_class(pitch: Pitch) -> int`: Return `pitch.pitch_class`
    - `from_midi(midi_number: int, prefer_sharps: bool = True) -> Pitch`: Lookup from `_MIDI_TO_PITCH_SHARP` or `_MIDI_TO_PITCH_FLAT`, compute octave as `(midi_number // 12) - 1`, pitch class as `midi_number % 12`
    - `to_frequency(pitch: Pitch, a4_hz: float = 440.0) -> float`: `a4_hz * (2 ** ((pitch.midi_number - 69) / 12))`
    - `from_frequency(hz: float, a4_hz: float = 440.0, prefer_sharps: bool = True) -> Pitch`: Compute nearest MIDI via `round(12 * math.log2(hz / a4_hz) + 69)`, then call `from_midi`
    - `pitch_in_scale(pitch: Pitch, scale: Any) -> bool`: `raise NotImplementedError("Scale membership requires Phase 3 scale library")`
    - `nearest_in_scale(pitch: Pitch, scale: Any) -> Pitch`: `raise NotImplementedError("Nearest in scale requires Phase 3 scale library")`
