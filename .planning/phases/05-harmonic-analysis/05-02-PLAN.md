       - Build histogram.
       - For each of 12 root pitch classes, rotate each of the 4 profiles (major, natural_minor, harmonic_minor, melodic_minor) and compute Pearson correlation.
       - Profile rotation: to test root_pc=N, rotate the profile so index 0 aligns with pitch class N. That is: `rotated = profile[N:] + profile[:N]` -- WRONG. The correct rotation: to correlate histogram against key of root R, rotate the PROFILE left by R positions, i.e., `rotated_profile = tuple(profile[(i - root_pc) % 12] for i in range(12))`. Actually, the simpler approach: rotate the HISTOGRAM right by root_pc (or equivalently, compare histogram[root_pc:] + histogram[:root_pc] against the unrotated profile).
       - Correct approach: `correlation = _pearson_correlation(histogram, rotated_profile)` where `rotated_profile[i] = profile[(i - root_pc) % 12]`.
       - Clip correlation to `max(0.0, correlation)`.
       - Track best (root_pc, mode, confidence).
       - Map winning root_pc to a Pitch: find the input pitch with that pitch_class (preserves spelling). If no input pitch has that pc, use sharp-default via the same `_PC_TO_PITCH_SHARP` pattern from scales.py: `[("c","n"), ("c","s"), ("d","n"), ("d","s"), ("e","n"), ("f","n"), ("f","s"), ("g","n"), ("g","s"), ("a","n"), ("a","s"), ("b","n")]`.

    3. `roman_numeral(chord: ChordMatch, key: KeyResult) -> RomanNumeral`:
       - Build the scale: `scale = get_scale(key.root, key.mode)` -- but `parallel_key` only supports "major"/"natural_minor". For `key.mode` in ("harmonic_minor", "melodic_minor"), use `get_scale(key.root, key.mode)` directly (scale_degree works on any Scale).

         - Try `degree = scale_degree(chord.root, parallel)`.

       - Return the list of HarmonicBeat objects.
