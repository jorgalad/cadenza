       @dataclass(frozen=True, slots=True)
       class ChordMatch:
           root: Pitch
           symbol: str       # Registry key: "maj", "m", "7", "dim7", etc.
           inversion: int    # 0-based: 0 = root position
           pitches: tuple[Pitch, ...]

    2. `_COMPLEXITY_RANK` dict mapping chord symbols to preference integers:
       - Triads (maj, m, dim, aug): 0
       - Sevenths (7, maj7, m7, m7b5, dim7, mM7, aug7): 1
       - sus/add: 1
       - Extended (9, maj9, m9): 2
       - 11ths: 3, 13ths: 4

    3. `identify_chord(pitches: tuple[Pitch, ...]) -> ChordMatch`:
       - Reduce input to `frozenset` of pitch classes.
       - Iterate all 12 root pitch classes (0..11) x all `_CHORD_REGISTRY` items.
       - For each: compute chord pitch class set = `frozenset((root_pc + s) % 12 for s in semitones)`.
       - If chord_pcs == input_pcs, it is a candidate.
       - Determine inversion: the bass note (lowest by MIDI number in the input) determines inversion. Find which position in the chord's semitone list corresponds to the bass note's pitch class. If bass_pc == (root_pc + semitones[inv]) % 12 for some inv, that is the inversion.
       - Score each candidate as tuple: `(inversion, _COMPLEXITY_RANK.get(symbol, 99), len(semitones))`.
       - Pick candidate with lowest score.
       - Determine root Pitch: find input pitch whose pitch_class matches root_pc. If none (root not sounded in inversion), use the cn serializer pattern to build a Pitch from the bass note context -- specifically, derive the root's step/accidental from the bass pitch by computing the interval down from bass to root.
       - Construct full chord pitches via `get_chord(root_pitch, symbol, best_inversion)`.
       - Raise `ValueError` if no candidates found.

    4. `realize_chord(root: Pitch, symbol: str, inversion: int = 0, octave: int = 4) -> tuple[Pitch, ...]`:
       - If root.octave differs from `octave`, create a new Pitch with the requested octave.
       - Delegate to `get_chord(root, symbol, inversion)`.
