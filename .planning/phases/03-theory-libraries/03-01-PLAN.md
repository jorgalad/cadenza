    **Pitch building algorithm** (`_build_pitch`):
    For 7-note scales, advance letter name by 1 per degree (degree_offset = index in pattern).
    For non-7-note scales, use a per-scale `_DEGREE_STEPS` mapping that defines the letter-name offset for each degree.

    Define `_DEGREE_STEPS: dict[str, tuple[int, ...]]` for non-standard scales:
    ```python
    _DEGREE_STEPS: dict[str, tuple[int, ...]] = {
        # 5-note scales: which 5 of 7 letter steps to use
        "major_pentatonic": (0, 1, 2, 4, 5),       # C D E G A
        "minor_pentatonic": (0, 2, 3, 4, 6),        # A C D E G (relative to A)
        "hirajoshi": (0, 1, 2, 4, 5),               # C D Eb G Ab
        "in_sen": (0, 1, 3, 4, 6),                  # C Db F G Bb
        "iwato": (0, 1, 3, 4, 6),                   # C Db F Gb Bb
        "yo": (0, 1, 3, 4, 5),                      # C D F G A
        # 6-note scales
        "blues": (0, 2, 3, 3, 4, 6),                # C Eb F Gb G Bb (G repeated area)
        "whole_tone": (0, 1, 2, 3, 4, 5),           # C D E F# G# A#
        "augmented": (0, 2, 2, 4, 4, 6),            # C Eb E G Ab B
        # 8-note scales
        "diminished": (0, 1, 2, 3, 3, 4, 5, 6),    # C D Eb F Gb Ab A B
        "diminished_half_whole": (0, 1, 2, 2, 3, 4, 5, 6), # C Db Eb E Gb G A Bb
        "bebop_dominant": (0, 1, 2, 3, 4, 5, 6, 6), # C D E F G A Bb B
        "bebop_major": (0, 1, 2, 3, 4, 5, 5, 6),   # C D E F G Ab A B
        "bebop_minor": (0, 1, 2, 3, 4, 5, 5, 6),   # C D Eb F G Ab A Bb
    }
    ```
    For any scale NOT in `_DEGREE_STEPS` and with exactly 7 notes, use sequential letter steps (0,1,2,3,4,5,6).

    The `_build_pitch(root: Pitch, degree_offset: int, semitone_offset: int) -> Pitch` function:
    1. `target_step_idx = (STEP_INDEX[root.step] + degree_offset) % 7`
    2. `target_step = _INDEX_TO_STEP[target_step_idx]`
    3. `target_midi = root.midi_number + semitone_offset`
    4. `base_pc = STEP_SEMITONES[target_step]`
    5. `octave = (target_midi - base_pc) // 12 - 1`
    6. `natural_midi = (octave + 1) * 12 + base_pc`
    7. `acc_semitones = target_midi - natural_midi`
    8. Map acc_semitones via `_SEMITONES_TO_ACC`; raise ValueError if out of range [-2, 2].
    9. Return `Pitch(step=target_step, accidental=_SEMITONES_TO_ACC[acc_semitones], octave=octave)`

    **`get_scale(root: Pitch, name: str) -> Scale`:**
    1. Resolve alias: `canonical = _SCALE_ALIASES.get(name, name)`
    2. Look up in `_SCALE_REGISTRY`; raise `ValueError(f"Unknown scale: {name!r}")` if not found
    3. Get degree steps: `_DEGREE_STEPS.get(canonical, tuple(range(len(intervals))))` -- for 7-note, range(7) gives (0,1,2,3,4,5,6)
    4. Build pitches using `_build_pitch(root, degree_steps[i], intervals[i])` for each i
    5. Return `Scale(root=root, name=canonical, pitches=tuple(pitches), intervals=intervals)`

    **`register_scale(name: str, intervals: list[int]) -> None`:**
    - Raise ValueError if name already in registry or aliases
    - Add to `_SCALE_REGISTRY[name] = tuple(intervals)`
