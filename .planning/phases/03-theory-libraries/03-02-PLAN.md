    **`get_chord(root: Pitch, symbol: str, inversion: int = 0) -> tuple[Pitch, ...]`:**
    1. Resolve alias
    2. Look up in registry -> get (semitones, degree_steps)
    3. Build pitches: `_build_pitch(root, degree_steps[i], semitones[i])` for each i
    4. Apply inversion: validate `0 <= inversion < len(pitches)`, then rotate bottom N pitches up one octave
    5. Return tuple

    **Inversion algorithm** (`_apply_inversion`):
    ```python
    def _apply_inversion(pitches: tuple[Pitch, ...], inversion: int) -> tuple[Pitch, ...]:
        if inversion < 0 or inversion >= len(pitches):
            raise ValueError(f"Inversion {inversion} out of range for {len(pitches)}-note chord")
        result = list(pitches)
        for _ in range(inversion):
            p = result.pop(0)
            result.append(Pitch(step=p.step, accidental=p.accidental, octave=p.octave + 1))
        return tuple(result)
    ```

    - Add to `_CHORD_REGISTRY[name] = (tuple(intervals), degree_steps)`

    **`diatonic_chords(scale_root: Pitch, scale_name: str, quality: str = 'triad') -> tuple[tuple[Pitch, ...], ...]`** (CHRD-06):
    ```
    1. scale = get_scale(scale_root, scale_name)
    2. Extend scale pitches to two octaves: extended = scale.pitches + tuple(Pitch(p.step, p.accidental, p.octave+1) for p in scale.pitches)
    3. stack_size = 3 if quality == 'triad' else 4 (for 'seventh')

       chord = tuple(extended[degree + i*2] for i in range(stack_size))
       -- This picks every other note: root, 3rd, 5th (, 7th)

    ```

    **`secondary_dominant(degree: int, key_root: Pitch, key_name: str) -> tuple[Pitch, ...]`** (CHRD-07):
